# Yerel arayüz kaynakları

- [Next.js kurulum](https://nextjs.org/docs/app/getting-started/installation):
  App Router, React, TypeScript ve yerel geliştirme akışı.
- [Tailwind PostCSS](https://tailwindcss.com/docs/installation/using-postcss):
  Tailwind 4 için resmi PostCSS kurulumu.
- [shadcn/ui Next.js](https://ui.shadcn.com/docs/installation/next):
  Yerel bileşen sahipliği ve token düzeni referansı. Button, Radix Slot ve
  class-variance-authority ile yerel kaynak olarak yazıldı; ücretli şablon yok.
- [21st.dev bileşen keşfi](https://21st.dev/community/components): sidebar,
  dashboard ve kart kategorileri tasarım referansı olarak incelendi. Lisansı
  doğrulanmayan üçüncü taraf bileşen kaynağı kopyalanmadı. Yerleşim, CSS ve
  dekoratif yörünge görseli proje içinde özgün olarak yazıldı.
- Lucide ikonları `lucide-react` paketinden gelir; paket lisans kayıtları
  dağıtımındaki `LICENSE` dosyasında korunur.
- Dışarıdan mağaza görseli, ekran görüntüsü, font veya logo indirilmedi.
  Hayali uygulama ikonları Lucide çizimleri ve yerel CSS renklerinden oluşur.

Sürüm, yazar ve lisans kayıtları npm paketlerinin package.json/LICENSE
dosyalarında; kesin bağımlılıklar package-lock.json içinde bulunur.
